What this version does — and doesn't

Runs reproducible chaos simulationsRetry policies, status patterns, duplicate deliveries and ordering faults.
Generates real HMAC-SHA256 locallyWeb Crypto API; secret and payload stay in this browser.
Persists scenarios and reportsLocalStorage; export/import workspace backup.
No real endpoint delivery yetServer-side proxy, endpoint auth and safe network isolation are future adapters.
No team/cloud syncMulti-user accounts, shared history and hosted report links are not included.
HookForge is intentionally a safe, local-first testing lab. The app never contacts an external endpoint by default and never claims a simulated delivery is a real webhook call.
