# HookForge Buyer FAQ v1.1

## What is being acquired?
A self-contained browser-local webhook reliability workbench, its source code, license, demo workflow, documentation and portability/reporting features.

## Is this a production webhook delivery service?
No. It is a local-first simulation and developer workflow MVP. It does not send real webhooks or contact user endpoints.

## Does it support real provider signatures?
The lab generates HMAC-SHA256 and includes educational provider-style presets. These are not certified drop-in implementations of each provider's exact timestamp, header, encoding and rotation rules. A production release must follow the current official provider documentation and tests.

## What is new in v1.1?
Batch reliability matrix, custom required-path contract checks, educational signature presets, scenario pack import/export and self-contained HTML run reports.

## Is there recurring revenue?
No. The product is pre-launch and pre-revenue; no customers or revenue are claimed.

## What would a buyer build next?
A secure server-side runner, endpoint allowlisting, team authentication, encrypted secrets, provider adapters, real retry/replay queues, hosted report links and cloud persistence.
