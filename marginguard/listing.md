## What it does

MarginGuard turns project economics into an action queue before margin problems become invoice surprises.

**Import -> Calculate -> Flag -> Investigate -> Review -> Resolve -> Export**

It is built around a specific B2B pain: fixed-fee project work can become unprofitable when hours, rework or unbilled scope drift beyond the plan.

## Implemented

- forecast gross margin;
- actual vs budget hours;
- forecast hours to completion;
- loaded cost per hour;
- unbilled scope exposure;
- configurable margin, scope and overrun thresholds;
- project risk scoring;
- project detail evidence;
- alert lifecycle;
- CSV import/export;
- JSON evidence packs;
- HTML audit reports;
- local browser persistence;
- responsive UI.
