# MarginGuard - Submit SaaS Project

## Product Name
MarginGuard

## Tech Stack
Self-contained HTML5, CSS3 and vanilla JavaScript; browser localStorage; Vercel static hosting; GitHub Actions + Playwright for browser smoke testing.

## Description
MarginGuard is a focused B2B profitability control tool for agencies and consultancies. It turns project fees, planned hours, logged delivery time and billing progress into an early-warning workflow: import project data, calculate forecast margin, flag risky projects, inspect the economics, tune business thresholds, and export portable reports. The MVP includes forecast gross margin, hour burn, unbilled-scope exposure, deterministic risk scoring, project details, CSV import/export, JSON evidence packs and HTML reports. It is intentionally lightweight and easy to extend with time-tracking, project-management, invoicing, authentication, Postgres, alerts and billing integrations.

## Problem Solved
Fixed-fee projects can lose margin when delivery hours, rework or unbilled scope drift beyond the original plan. Small agencies and consultancies often discover this too late because project economics are spread across time-tracking, spreadsheets and invoicing tools. MarginGuard gives operators one place to see forecast margin and act before the project closes.
