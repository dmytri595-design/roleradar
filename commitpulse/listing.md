# CommitPulse — Sale Listing

**Product Name:** CommitPulse

**Tech Stack:** HTML, CSS, JavaScript, Browser File API, localStorage

**Description:** CommitPulse is a focused supplier-confirmation workflow for manufacturers, importers and distributors. Teams import an open purchase-order export, see which commitments are missing, group follow-ups by supplier, preview a no-login supplier request, record confirmations/exceptions, and export the updated dataset.

**Problem Solved:** Procurement teams often spend a disproportionate amount of time chasing suppliers for delivery dates and quantities. CommitPulse isolates that micro-workflow and turns it into a repeatable confirmation loop without replacing the existing ERP.
