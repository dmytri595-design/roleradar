# CommitPulse — Sale Listing

**Product Name:** CommitPulse

**Tech Stack:** HTML, CSS, JavaScript, Browser File API, localStorage

**Description:** CommitPulse is a focused supplier-confirmation workflow for manufacturers, importers and distributors. Teams import open purchase orders, identify missing commitments, create one grouped request per supplier, give suppliers a no-login multi-PO confirmation page, record date/quantity changes as exceptions, and export the normalized result.

**Problem Solved:** Procurement teams spend too much time manually chasing suppliers for delivery dates and quantities. CommitPulse isolates that micro-workflow and provides a repeatable confirmation loop without replacing the existing ERP.

**Status:** Working MVP / pre-launch / pre-revenue

**Users:** 0 claimed
