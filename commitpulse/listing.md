# CommitPulse — Sale Listing v1.2

**Product Name:** CommitPulse

**Tech Stack:** HTML, CSS, JavaScript, Browser File API, localStorage

**Description:** CommitPulse is a focused supplier-confirmation workflow for small manufacturers, importers and distributors. Import open purchase orders, identify missing commitments, create grouped supplier requests, let suppliers confirm multiple POs in one response, triage delivery/quantity exceptions, produce grouped email drafts, track follow-up dates, and export data and reports.

**Problem Solved:** Procurement teams spend too much time manually chasing suppliers for delivery-date and quantity commitments. CommitPulse provides a repeatable confirmation loop alongside an existing ERP.

**Current Features:** CSV import + validation, request center, multi-PO supplier response, exception desk, reminder queue, manual PO management, priorities, analytics, supplier scorecard, JSON backup/restore, CSV exports, HTML weekly report and activity history.

**Status:** Working MVP / pre-launch / pre-revenue

**Users:** 0 claimed

**Monthly Revenue:** $0 / pre-revenue

**Honesty note:** This is browser-local. Email messages are drafts only; links are not server-backed tokens. Cloud persistence, authentication, collaboration, and ERP write-back are not implemented.
