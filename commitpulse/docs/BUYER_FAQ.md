# Buyer FAQ — v1.2

### Does CommitPulse replace my ERP?
No. It is a confirmation workflow layer that starts with a PO export.

### Can a supplier confirm multiple POs?
Yes. A grouped request renders multiple POs with a date, quantity and optional note for each.

### Does it send real email reminders?
No. It creates copyable drafts and can hand them off to the configured mail app. The demo does not deliver mail.

### Are request links cross-device?
Not in this release. Browser-local storage means the request state is shared only in the same browser profile. Production must use server-backed signed tokens.

### Can I edit and create POs?
Yes, the buyer can create/edit POs, set priority, price and the next follow-up date.

### Can I export or restore workspace state?
Yes. CSV exports and a JSON workspace backup/restore are included.

### Are there paying users or revenue?
None are claimed. Current positioning is pre-launch / pre-revenue.
