# Copy-ready sale submission — CommitPulse v1.2

**Product Name:** CommitPulse

**Tech Stack:** HTML5, CSS3, Vanilla JavaScript, Browser File API, localStorage

**Description:** CommitPulse is a focused supplier-confirmation workflow for small manufacturers, distributors and importers. Import and validate open POs, create grouped supplier confirmation requests, capture multi-PO date/quantity commitments, resolve exceptions, track follow-up dates, prepare grouped email drafts, manage PO priorities, review supplier analytics, and export CSV data, activity, HTML reports or JSON workspace backups. Designed to sit beside an existing ERP.

**Problem Solved:** Procurement teams spend too much time chasing suppliers for delivery-date and quantity commitments across email and spreadsheets. CommitPulse structures that loop with supplier-grouped requests, multi-PO responses, exception resolution, follow-up tracking and reporting without replacing the ERP.
