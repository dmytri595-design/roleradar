# Copy-ready sale submission

**Product Name**: CommitPulse

**Tech Stack**: HTML, CSS, JavaScript, Browser File API, localStorage

**Description**: CommitPulse is a focused supplier-confirmation workflow for small manufacturers, distributors and importers. Import open POs, create grouped supplier requests, capture multi-PO confirmations, review date/quantity exceptions, generate email drafts, track follow-up dates, and export analytics and workspace backups.

**Problem Solved**: Procurement teams spend too much time chasing suppliers for delivery dates and quantities. CommitPulse gives that follow-up loop a dedicated workflow without replacing the ERP.
