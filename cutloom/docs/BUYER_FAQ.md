# Cutloom - buyer FAQ

## Is Cutloom production SaaS?

No. It is a working creator-tool MVP / pre-launch / pre-revenue asset.

## Is there any revenue or customer traction?

No claimed paying users and $0 MRR.

## Does it really create a video?

Yes. The MVP includes a browser-side WebM rendering path using Canvas and MediaRecorder where the browser exposes the required APIs. The output is a lightweight procedural draft, not a full NLE render pipeline.

## Are the demo visuals licensed stock footage?

No. Demo visuals are procedural/synthetic treatments included to demonstrate the workflow.

## Is an API key required?

No API key is required for the current demo.

## Is a database required?

No. The current project is local-first and uses browser persistence.

## Is AI already connected?

No. The current MVP does not claim live AI provider usage.

## Can the buyer add real media?

Yes. The natural next product layer is upload/storage, media metadata, thumbnails, a real timeline and server-side rendering.

## Can it become collaborative?

Yes. Cloud project storage, comments, approvals and version history can be layered on top.

## What is included in the sale?

Current product source, demo materials, synthetic sample project, documentation, smoke test and product-specific handoff materials included in the sale package.

## What is not silently included?

No promise of customers, revenue, domains, trademarks, proprietary third-party assets, paid AI provider accounts, or post-sale development unless separately agreed in writing.
