# Cutloom — acquisition brief

Cutloom is a browser-local creator-tool MVP focused on turning a script into a storyboard, timeline, captions and a rendered WebM draft.

## Product snapshot

- Status: working MVP / pre-launch / pre-revenue
- Paying users: 0 claimed
- MRR: $0 claimed
- Suggested asking price: $4,900 USD one-time
- Live demo: https://cutloom-demo.vercel.app

## Why it is differentiated

The interaction model is designed as a miniature editing desk rather than a CRUD dashboard: a central cinematic canvas, inspector, scene cards, script desk, visual shelf and multi-track timeline.

## Current capability

The demo supports scene editing, 16:9 and 9:16 formats, local persistence, project import, JSON/CSV/HTML exports, caption planning and browser-side WebM rendering when MediaRecorder is available.

## Extension path

Cloud storage, real media uploads, collaborative review, transcription/TTS, AI storyboarding, stock-media connectors, brand kits, version history and billing can be added later.

## Accuracy note

Demo scenes and visual treatments are synthetic. No customers, revenue, licensed media library, AI provider usage or production contracts are claimed.
