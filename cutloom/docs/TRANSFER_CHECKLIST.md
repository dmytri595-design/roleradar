# Cutloom - transfer checklist

## Before closing

- Confirm final purchase price and payment milestones.
- Confirm the exact assets included in the transaction.
- Confirm whether the buyer requires a standalone GitHub repository.
- Confirm whether the buyer wants the Vercel project transferred or recreated in their account.
- Confirm whether any custom domain, social account or trademark is part of the deal; none is assumed.

## Technical handoff

- Deliver Cutloom-only source package.
- Deliver current sample project.
- Deliver buyer brief and technical handoff.
- Explain local run command.
- Explain browser-local storage behavior.
- Explain WebM renderer limitations.
- Provide repository and live demo links.
- Run the latest smoke test after any material source change.

## Ownership / IP

The parties should execute a written IP/asset transfer covering the code and product materials actually included in the transaction. Third-party rights, trademarks, paid accounts and future work should be listed separately.

## Post-close support

Any support window should be explicitly agreed in writing. The MVP does not silently include ongoing maintenance or feature development.
