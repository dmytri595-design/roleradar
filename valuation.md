## Positioning

RoleRadar is intentionally below the more developed $8k–$9k class because it is still browser-local and does not yet include production authentication, backend persistence or native Okta / Entra / Google Workspace connectors.

It is above a simple code dump because the MVP contains a coherent B2B workflow:

**Import → Normalize → Score → Investigate → Assign → Resolve → Re-run → Export**

It also includes deterministic risk scoring, configurable policy thresholds/weights, findings lifecycle, owner/due-date tracking, persistence and audit artifacts.
