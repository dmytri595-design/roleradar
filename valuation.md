# RoleRadar - Pricing Rationale (2026)

## Recommended ask

**$4,500 USD - one-time acquisition**

## Positioning

RoleRadar is a working, focused B2B security workflow, not a finished enterprise platform and not a code-only concept.

The asset includes a coherent workflow:

**Import -> Normalize -> Score -> Investigate -> Assign -> Resolve -> Re-run -> Export**

It also includes deterministic risk scoring, configurable policy thresholds and weights, findings lifecycle, owner/due-date tracking, browser-local persistence, and portable audit artifacts.

## Why $4,500

The price deliberately sits in the early-stage micro-SaaS range while recognizing that the product is more developed than a simple MVP code dump.

The main constraints on the price are clear:

- no customers or MRR;
- pre-launch;
- browser-local architecture;
- no production authentication;
- no backend persistence;
- no native Okta / Microsoft Entra / Google Workspace integrations.

The main assets supporting the price are:

- working live product;
- clear B2B security positioning;
- complete review workflow;
- explainable scoring engine;
- remediation lifecycle;
- configurable policies;
- CSV / JSON / HTML audit exports;
- documented extension path;
- MIT-licensed source;
- automated validation and live browser smoke coverage.

The seller should not advertise a revenue multiple because there is no revenue to support one.
